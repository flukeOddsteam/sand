# แซนด์ (Sand) — AI ส่วนตัวที่สร้างเอง และดูสมองได้ทุกขั้น

แซนด์คือ AI ที่รันบนเครื่องคุณ มีสมองให้เลือก 2 แบบ:

- **🌱 แซนด์ทารก** — สมองที่เขียนเองทุกสูตรและ**เกิดจากศูนย์** เรียนภาษาทีละตัวอักษรจากสิ่งที่คุณสอนและสิ่งที่มันออกไปอ่านเอง
- **🎓 สมองโต** — เครื่องยนต์ที่เขียนเองทุกสูตร โหลดความรู้จากโมเดลเปิด (Qwen3 / Typhoon) จึงตอบคำถามได้ฉลาดทันที

ทั้งสองแบบ**เปิดดูข้างในได้แบบเรียลไทม์**: เห็นทุกตัวอักษรที่คิด พร้อมสูตรจริงที่แทนค่าตัวเลข

## เริ่มใช้งาน (Mac ชิป M)

1. ต้องมี **Python 3.10–3.14** (ถ้ามีแต่ 3.15 ให้ติดตั้ง 3.13 เพิ่มจาก https://www.python.org/downloads/macos/ ใช้คู่กันได้)
2. เปิด Terminal แล้วรัน
   ```
   cd ~/Desktop/sand
   ./start-mac.command
   ```
   ครั้งแรกจะสร้าง `.venv` แล้วติดตั้ง PyTorch, tokenizers, numpy ให้เอง (~200MB) สคริปต์หา Python เวอร์ชันที่ใช้ได้ให้อัตโนมัติ
3. เบราว์เซอร์จะเปิด http://127.0.0.1:7777

**ปิด:** กด `Ctrl + C` ใน Terminal (สมองถูกบันทึกให้อัตโนมัติ)
**อัปเดตเป็นรุ่นล่าสุด:** `git pull` แล้วเปิดใหม่
**ถ้าขึ้นว่าแซนด์เปิดอยู่แล้ว:** `lsof -ti :7777 | xargs kill` แล้วเปิดใหม่
(Linux ใช้ `start-linux.sh`)

## เริ่มใช้งาน (Windows)

1. ต้องมี **Python 3.10–3.14 รุ่น 64-bit** จาก https://www.python.org/downloads/windows/ (แนะนำ 3.12 เลือก "Windows installer (64-bit)" และติ๊ก **Add python.exe to PATH**)
2. เปิด cmd แล้วรัน (หรือดับเบิลคลิก `start-windows.bat`)
   ```
   cd %USERPROFILE%\Desktop\sand
   start-windows.bat
   ```
   สคริปต์หา Python ที่ใช้ได้ให้เอง (ผ่านตัวเรียก `py`) ถ้า `.venv` เดิมใช้ Python ที่ไม่รองรับจะสร้างใหม่ให้ ถ้ามีการ์ดจอ NVIDIA จะลองติดตั้ง PyTorch รุ่น GPU ก่อน
3. เบราว์เซอร์จะเปิด http://127.0.0.1:7777

**ถ้าขึ้นว่าหา torch ไม่เจอ (`from versions: none`):** แปลว่า Python เป็นรุ่น 32-bit หรือเวอร์ชันที่ PyTorch ไม่รองรับ ติดตั้ง Python 3.12 (64-bit) แล้วรันใหม่
**ถ้าขึ้นว่าแซนด์เปิดอยู่แล้ว:** `netstat -ano | findstr :7777` แล้ว `taskkill /PID <เลขท้ายสุด> /F`

## 🌱 แซนด์ทารก: สมองที่เขียนเองจากศูนย์ (`brain.py`)

อ่านทีละตัวอักษร (ภาษาไทยไม่มีเว้นวรรค จึงเหมาะกับการอ่านแบบนี้) แล้วเดาตัวถัดไป:

```
x = E[ตัวอักษร] + P[ตำแหน่ง]
ทุกชั้น:   A = softmax(Q·Kᵀ / √d_k)          ← มองย้อนกลับไปอ่านตัวก่อนหน้า
           x = x + A·V·W_o
           x = x + GELU(LayerNorm(x)·W₁)·W₂  ← คิดต่อ
p(ตัวถัดไป) = softmax(z / T)
```

ฝึกด้วย `L = −(1/N) Σ ln p(ตัวที่ถูก)` แล้วปรับน้ำหนักด้วย AdamW `θ ← θ − η · m̂/(√v̂+ε)` บน GPU ของ Mac (Metal) · บันทึกใน `sand_brain.pt`

| ขนาดสมอง | ชั้น | d | มองย้อน | น้ำหนัก |
|---|---|---|---|---|
| เล็ก | 4 | 128 | 128 ตัวอักษร | ~0.8 ล้าน |
| กลาง (เริ่มต้น) | 6 | 256 | 256 ตัวอักษร | ~4.9 ล้าน |
| ใหญ่ | 8 | 384 | 256 ตัวอักษร | ~14.4 ล้าน |

## 🎓 สมองโต: เครื่องยนต์ของเรา + ความรู้จากโมเดลเปิด (`bigbrain.py`)

กด **🧠** มุมขวาบน → ดาวน์โหลด (ครั้งแรกครั้งเดียว ต่อได้ถ้าหลุด) → **ใช้สมองนี้**

| สมอง | น้ำหนัก | ขนาดไฟล์ | เหมาะกับ |
|---|---|---|---|
| Qwen3 0.6B | 0.6 พันล้าน | ~1.5 GB | เครื่องช้า / อยากได้คำตอบเร็ว |
| **Qwen3 1.7B** | 1.7 พันล้าน | ~4.1 GB | **แนะนำสำหรับ RAM 8GB** · คิดก่อนตอบได้ |
| Typhoon 2.5 (Qwen3 4B) | 4 พันล้าน | ~8.1 GB | ภาษาไทยเก่งที่สุด · ต้อง RAM 16GB (ต่ำกว่านั้นจะบีบเป็น int8 ช้าลง) |

- **เขียนเองตรงไหน:** ตัวที่ “คิด” คือ `bigbrain.py` เขียนเองทุกสูตร — RMSNorm, RoPE, Grouped-Query Attention, SwiGLU, KV cache, การสุ่ม top-k/top-p — อ่านไฟล์ safetensors เอง ไม่ใช้ Ollama หรือ transformers · ตรวจแล้วตรงกับโค้ดต้นแบบของ Qwen3 (ต่างกันไม่เกิน 0.0000004)
- **ไม่ได้เขียนเอง:** น้ำหนัก (ความรู้) ทีม Qwen ฝึกมา · ตัวตัดคำใช้ไลบรารี `tokenizers` · คูณเมทริกซ์ด้วย PyTorch
- **💭 คิดก่อนตอบ:** เปิดได้ในหน้าต่างเลือกสมอง จะเห็นความคิดสดในแชทก่อนคำตอบ
- **สอนได้:** สิ่งที่สอนในแท็บข้อมูลฝึกถูกส่งให้อ่านก่อนตอบทุกครั้ง · ข้อความที่ป้อนและหน้าเว็บที่เคยอ่านจะถูกค้นส่วนที่เกี่ยวข้องมาให้อ่านด้วย
- **ฝึกน้ำหนักเพิ่มไม่ได้บน Mac 8GB** (แรมไม่พอ) แซนด์ทารกยังฝึกได้ตามเดิม · เมื่อโหลดสมองโต การฝึกแซนด์ทารกจะหยุดอัตโนมัติเพื่อคืนแรม

## 🌐 เรียนรู้จากอินเทอร์เน็ต (ปิดไว้เป็นค่าเริ่มต้น)

เปิดที่แท็บ 📚 ข้อมูลฝึก → **อนุญาตให้แซนด์ใช้อินเทอร์เน็ต**

- **อ่านจาก:** ทั้งเว็บ + Wikipedia / ทั้งเว็บเท่านั้น / Wikipedia เท่านั้น
- **เครื่องมือค้นหา:** DuckDuckGo (ฟรี ไม่ต้องสมัคร แต่ไม่มี API ทางการ ถ้าค้นถี่อาจถูกขอให้ช้าลง) หรือ Tavily (เสถียรกว่า · สมัครฟรีที่ tavily.com ได้ 1,000 ครั้ง/เดือน · ใส่ API key ในแอป เก็บไว้ในเครื่องคุณเท่านั้น)
- **🌱 แซนด์ทารกออกไปอ่านเอง** — ตั้งหัวข้อไว้ จะค้นจากเว็บ/Wikipedia แล้วเปิดอ่านทีละหน้า · ไม่ตั้ง จะสุ่มบทความ Wikipedia · ตั้งความถี่และจำนวนต่อวันได้ · เอาไปฝึกอัตโนมัติ (สูตร `w_web`)
- **🎓 สมองโตค้นก่อนตอบ** — คิดคำค้นเอง → ค้น → เปิดอ่าน 2 หน้า (ต่างเว็บกัน) → ตอบพร้อมลิงก์ที่มา → จำไว้ใช้ตอนออฟไลน์ · พิมพ์ `ค้น: …` เพื่อบังคับค้น

### 📖 ดูแซนด์อ่านแบบเรียลไทม์

- **ขั้นตอนสด:** อยากรู้เรื่องอะไร → ค้นด้วยอะไร → เจอกี่หน้า → เช็ก robots.txt → เปิดเว็บไหน → ข้ามเพราะอะไร → ได้เนื้อความกี่ตัวอักษร → เก็บไว้ฝึก
- **อ่านทีละตัวอักษร:** แซนด์ทายตัวถัดไปก่อนเสมอ ตัวอักษรไหลเข้ามาพร้อมสี 🟢 ทายถูก (รู้อยู่แล้ว) → 🔴 ทายผิด (เรื่องใหม่) · คลิกตัวไหนก็ได้ ดู 3 อันดับที่ทาย และความประหลาดใจ `s = −log₂ p(ตัวจริง)`
- **อ่านจบ:** loss ของบทความเทียบกับปกติ และช่วงที่แซนด์ประหลาดใจที่สุด (สิ่งที่ยังไม่รู้)
- **พิสูจน์การเรียนรู้:** ฝึกครบ 500 ก้าวหลังอ่าน แซนด์กลับมาวัดบทความเดิมซ้ำ แล้วบอกว่า “เข้าใจขึ้น X%”

### อ่านแล้วแซนด์ “รู้” จริงไหม

| | ได้อะไรจากการอ่าน | ถามเรื่องที่อ่านแล้วตอบได้ไหม |
|---|---|---|
| 🌱 แซนด์ทารก | น้ำหนักในสมองเปลี่ยนจริงตอนฝึก — เดาข้อความแนวนั้นได้แม่นขึ้น (วัดได้ด้วย “เข้าใจขึ้น X%”) | ยังไม่ค่อยได้ เพราะบทความเป็นความเรียง ไม่ใช่ถาม-ตอบ และสมองยังเล็ก |
| 🎓 สมองโต | น้ำหนักไม่เปลี่ยน แต่ทุกหน้าที่อ่าน (รวมที่แซนด์ทารกอ่าน) เก็บในคลังความรู้ | ได้ ถ้าคำถามใช้คำใกล้เคียงกับในบทความ — ค้นจากคลังแล้วอ่านก่อนตอบ แม้ปิดอินเทอร์เน็ต |

ทดสอบเอง: ให้แซนด์อ่านบทความ → ปิดอินเทอร์เน็ต → ใช้สมองโตถามเรื่องในบทความนั้น

### มารยาทและความปลอดภัยของตัวอ่านเว็บ (`web.py`)

- เคารพ `robots.txt` ทุกเว็บ · เว้นระยะอย่างน้อย 2 วินาทีต่อเว็บ · Wikipedia ใช้ API ทางการ ไม่เกิน 1 ครั้งต่อวินาที
- อ่านเฉพาะหน้าเว็บข้อความ ตัดเมนู โฆษณา คุกกี้ และส่วนท้ายเว็บทิ้ง
- ไม่ยอมเปิดที่อยู่ในเครือข่ายภายใน (เช่น 192.168.x.x, localhost) แม้ผลค้นหรือการ redirect จะพาไป
- เปิดแล้วแซนด์ไม่ออฟไลน์ 100% · ข้อมูลในเว็บผิดได้ แซนด์จึงแนบลิงก์ที่มาเสมอ · เนื้อหาที่อ่านเก็บไว้ในเครื่องคุณเพื่อใช้ส่วนตัว

- เขียนเป็น “ต้นไม้บทสนทนา” (ผู้ใช้พูดแบบไหน → แซนด์ตอบได้แบบไหน → ผู้ใช้พูดต่อ …) แล้วสุ่มคำ (อาหาร เกม ที่เที่ยว ชื่อสัตว์เลี้ยง) ทุกเส้นทางจึงต่อกันรู้เรื่อง · เพิ่มสถานการณ์เองได้ในไฟล์นี้
- ตอนคุย แซนด์ทารกเห็นเฉพาะ **บทสนทนาปัจจุบัน** (เว้นเกิน 30 นาที = เริ่มเรื่องใหม่) เหมือนตอนฝึกที่แต่ละเรื่องคั่นด้วยบรรทัดว่าง จึงไม่เอาเรื่องเก่าเมื่อวานมาปน
- สมองเดิมที่ฝึกไว้ไม่ต้องลบ เปิดแอปแล้วกด ▶ ฝึก จะเรียนบทใหม่ต่อจากความรู้เดิม (ยิ่งฝึกนาน ยิ่งตอบต่อเรื่องได้ดี — สมองกลางควรฝึกอย่างน้อยหลายพันก้าว)
- **บทสนทนาไม่ถูกบทความกลบ:** ทุกก้าวฝึก ครูฝึกหยิบครึ่งหนึ่งของข้อความมาจาก “กองบทสนทนา” (บทเรียนตั้งต้น สิ่งที่สอน 👍 บทสนทนาที่ไปเรียนมา สำเนาพิมพ์ผิด) ที่เหลือจากข้อมูลทั้งหมด · ปรับได้ที่สูตร `p_chat` (0 = แบบเดิม) — แต่ก่อนถ้าแซนด์อ่านเว็บไปเยอะ บทสนทนาจะเหลือแค่ส่วนเล็กๆ ของการฝึก
- **คิดหลายแบบแล้วเลือก:** ตอนตอบ แซนด์ทารกคิดคำตอบ 4 แบบ (ปรับได้ด้วยแถบ “คิดกี่แบบ” ในแท็บสมองสด) แล้วเลือกแบบที่สมองมั่นใจที่สุด `(1/N) Σ ln p(ตัวอักษร | บทสนทนา)` ช่วยตัดคำตอบที่เพี้ยนกลางประโยคทิ้ง · เห็นคะแนนและแบบที่ไม่เลือกในบรรทัด 🎲 เหนือคำตอบ · สูตร `rerank_b` (β) เพิ่มแรงเลือกคำตอบที่ “เฉพาะกับสิ่งที่พูด” ได้ แต่จากที่ทดลอง β สูงทำให้เลือกประโยคแปลกๆ จึงตั้งไว้ 0
- **คะแนน “คุยต่อเรื่องได้”** (แท็บ 📈 การฝึก): ข้อสอบ 40 ข้อ แต่ละข้อมีบทสนทนา 1–3 รอบ + คำตอบที่ถูก + คำตอบจากอีกเรื่อง ได้คะแนนเมื่อ `log p(ถูก | บทสนทนา) > log p(เรื่องอื่น | บทสนทนา)` เดาสุ่มได้ 50% วัดทุก 500 ก้าว
- **บทสนทนาที่สมองโตแต่ง** เก็บไว้ทั้งเรื่อง (หลายรอบต่อเนื่อง) ไม่ใช่แค่คู่ถาม-ตอบเดี่ยว แซนด์ทารกจึงได้เรียนการคุยต่อเรื่องจากบทที่หลากหลายกว่าบทเรียนตั้งต้น
- **ตรงไปตรงมา:** ทดลองสมองเล็ก 12,000 ก้าว (CPU) คะแนนคุยต่อเรื่อง ~90% ตอบถูกเรื่องในสถานการณ์ที่เคยเรียน แต่ถ้าพูดประโยคที่ไม่คล้ายบทเรียน ยังหยิบประโยคจากเรื่องอื่นมาตอบได้ เพราะสมองทารกยังจำเป็นประโยคมากกว่าเข้าใจ · ทางที่ช่วยมากที่สุด: ฝึกนานๆ บนสมองกลาง/ใหญ่ + ให้สมองโตแต่งบทสนทนาสอนเยอะๆ (หลายร้อยเรื่อง) + กด ✏️ สอนคำตอบที่ถูกเมื่อแซนด์ตอบผิดเรื่อง

**คุยแบบมนุษย์ด้วยสมองโต** — ในหน้าต่างเลือกสมอง ตั้ง “สไตล์การคุย” เป็น 🗣️ คุยแบบมนุษย์ (ค่าเริ่มต้น):
- ตอบภาษาเดียวกับที่คุณพิมพ์ ระดับภาษาเดียวกัน คุยเล่นตอบสั้น 1–2 ประโยค ตอบรับความรู้สึกก่อน บางครั้งถามกลับ
- ใช้ภาษาพูดแบบแชท ไม่ลงท้ายครับทุกประโยค ไม่พูดแบบหุ่นยนต์ (“มีอะไรให้ช่วยอีกไหม”, “ในฐานะ AI”) · มีตัวอย่างน้ำเสียงในคำสั่งระบบให้สมองโตเลียนแบบ
- ข้อความคุยเล่นสั้นๆ ตอบทันทีโดยไม่คิดในใจก่อน (เร็วเหมือนแชท) · ถ้าขอให้อธิบาย คำนวณ หรือเขียนโค้ด จะคิดก่อนตอบตามปกติ
- จำบทสนทนาปัจจุบันย้อนหลัง ~10 รอบ (เว้นเกิน 3 ชั่วโมง = เริ่มเรื่องใหม่) · บอก “ผมชื่อ…” หรือ “my name is …” แซนด์จะจำชื่อไว้เรียก (สั่งลืมได้ในหน้าต่างเลือกสมอง)
- อยากได้คำตอบละเอียดเป็นขั้นตอนแบบเดิม เลือก 📘 ผู้ช่วย

**👩‍🏫 สมองโตเป็นครูสอนแซนด์ทารกคุย** — โหลดสมองโต แล้วกด “ให้สมองโตสอน” ในการ์ดเรียนการพูดคุย: สมองโตจะแต่งบทสนทนาสั้นๆ แบบคนแชทกัน 24 หัวข้อ (กินข้าว เหนื่อยงาน เกม ปลอบใจ วางแผนเที่ยว …) ในภาษาที่ติ๊กไว้ บางบทผู้ใช้พิมพ์ผิดด้วย แล้วเก็บเป็นบทเรียนให้แซนด์ทารก ไม่ต้องใช้อินเทอร์เน็ต · สอนเสร็จให้ปิดสมองโตแล้วกด ▶ ฝึก

**เดาคำพิมพ์ผิด (`typos.py`)** ทำ 2 ทาง:

1. **ตอนฝึก** — ทุกรอบ ครูฝึกทำ “สำเนาพิมพ์ผิด” ของบทสนทนาบางส่วน (สัดส่วนตามสูตร `p_typo`): กดตัวข้างๆ บนแป้น ตกตัว กดซ้ำ สลับตัว วรรณยุกต์ผิด พยัญชนะเสียงเดียวกัน (ส/ศ/ษ, ท/ธ) ภาษาพูด (ครับ→คับ) และลืมเปลี่ยนแป้น — **ฝั่งผู้ใช้ผิด แต่คำตอบยังถูก** สมองจึงเรียนว่าคำผิดแปลว่าอะไร
2. **ตอนคุย** — ถ้าพิมพ์ลืมเปลี่ยนแป้น เช่น `ต่อinternetwfh0ib'q` แซนด์ลองแปลงทุกช่วงที่เป็นไปได้ แล้วให้สมองตัวเองอ่านทุกแบบ เลือกแบบที่ loss ต่ำสุด
   `L(x) = −(1/N) Σ ln p(xᵢ | x₍<ᵢ₎)` → ได้ `ต่อinternetได้จริงๆ` (คำอังกฤษจริงอย่าง internet ไม่ถูกแปลง) · ตอนสมองยังเด็ก (ฝึก <500 ก้าว) ใช้รูปแบบตัวอักษรช่วยตัดสินแทน · ข้อความที่แก้จะขึ้นบรรทัดสีทอง ⌨️ เหนือคำตอบ

## 📚 ข้อมูลฝึก (`data/`)

ชุดข้อมูลที่เขียนขึ้นใหม่ทั้งหมด ป้อนได้ที่แท็บ 📚 ข้อมูลฝึก → **📄 เปิดไฟล์ .txt** (เลือกหลายไฟล์พร้อมกันได้)

| ไฟล์ | เนื้อหา |
|---|---|
| `1-บทสนทนา.txt` | บทสนทนาชีวิตประจำวัน ~130 คู่ (ทักทาย ความรู้สึก ให้กำลังใจ เรื่องของแซนด์เอง) |
| `2-ความรู้รอบตัว.txt` | ถาม-ตอบความรู้ ~120 ข้อ (ดาราศาสตร์ วิทยาศาสตร์ ร่างกาย ประเทศไทย ภูมิศาสตร์ คอมพิวเตอร์ สัตว์) |
| `3-เรื่องเล่า.txt` | นิทานและความเรียงสั้น 15 เรื่อง สำหรับฝึกภาษาไทยที่เป็นธรรมชาติ |
| `4-คณิตศาสตร์.txt` | 1,136 ข้อที่สร้างด้วยโปรแกรม (สูตรคูณ หาร บวกลบสองหลัก เปรียบเทียบ คู่/คี่ อ่านตัวเลขไทย) |
| `5-หลายภาษาและคำผิด.txt` | ทักทาย/คุยสั้นๆ 11 ภาษา (ตอบเป็นภาษาเดียวกับที่ถาม) + คำไทยที่มักเขียนผิด + ตัวอย่างพิมพ์ผิด — รวมอยู่ในบทเรียนตั้งต้นแล้ว |

ไฟล์ถาม-ตอบใช้รูปแบบ `ผู้ใช้: … / แซนด์: …` เหมือนตอนคุยจริง อยากเพิ่มเองก็เขียนไฟล์ .txt รูปแบบเดียวกันแล้วป้อนเข้าไป

## ตรงไปตรงมาเรื่องความฉลาด

- AI อย่าง Claude ฝึกด้วยข้อความหลายล้านล้านคำบนการ์ดจอหลายพันใบ แซนด์ทารกฝึกบนเครื่องเดียว จึงจะไม่มีวันฉลาดเท่า แต่เรียนสิ่งที่คุณสอนได้จริง และคุณเห็นทุกขั้นของการคิด
- สมองโต Qwen3 1.7B ตอบความรู้ทั่วไป อธิบาย และคำนวณได้ราวมัธยมปลายถึงต้นปริญญาตรีในหลายเรื่อง แต่ยังผิดได้ · เครื่อง 16GB ขึ้นไปใช้ Typhoon 2.5 จะเก่งภาษาไทยขึ้นชัดเจน
- **ทำให้แซนด์ทารกเก่งขึ้น:** เปิดฝึกนานๆ · ป้อนข้อความไทยหลากหลาย (ใช้เฉพาะข้อความที่คุณมีสิทธิ์ใช้) · สอนคู่ถาม-ตอบ · เปลี่ยนเป็นสมองใหญ่เมื่อมีข้อมูลเยอะ
- ถ้าเส้น loss ตอนฝึก (สีทอง) ต่ำกว่าเส้นข้อความใหม่ (สีเขียว) ห่างขึ้นเรื่อยๆ แปลว่ากำลัง “ท่องจำ” มากกว่า “เข้าใจ” ควรป้อนข้อมูลใหม่เพิ่ม
