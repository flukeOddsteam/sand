# แซนด์ (Sand) — AI ที่สร้างขึ้นเองตั้งแต่ศูนย์

แซนด์ไม่ได้ยืมสมองใคร ทุกสูตรในสมองเขียนขึ้นเองใน `brain.py` และแซนด์เกิดมาโดยไม่รู้อะไรเลย
ตอนแรกจะพิมพ์ตัวอักษรมั่วๆ แล้วค่อยๆ เรียนภาษาจากบทเรียนตั้งต้น สิ่งที่คุณสอน และข้อความที่คุณป้อนให้อ่าน
ทุกอย่างรันและเรียนรู้บนเครื่องคุณ ไม่มีข้อมูลออกไปไหน

## เปิดใช้งาน (Mac ชิป M)

1. ต้องมี Python 3.10+ ถ้ายังไม่มี ติดตั้งจาก https://www.python.org/downloads/
2. ดับเบิลคลิก **`start-mac.command`**
   - ครั้งแรกจะติดตั้ง PyTorch ให้อัตโนมัติ (ราว 200MB)
   - ถ้า Mac เตือนว่าเปิดไม่ได้: คลิกขวาที่ไฟล์ → Open
3. เบราว์เซอร์จะเปิด http://127.0.0.1:7777 แล้วแซนด์เริ่มฝึกเองทันที

แซนด์ฝึกด้วย GPU ของ Mac (Metal/MPS) ถ้าปิดโปรแกรม สมองจะถูกบันทึกไว้ใน `sand_brain.pt` เปิดใหม่ก็ฝึกต่อจากเดิม
(Windows ใช้ `start-windows.bat` · Linux ใช้ `start-linux.sh`)

## สมองของแซนด์ทำงานยังไง

แซนด์อ่านทีละตัวอักษร (ภาษาไทยไม่มีเว้นวรรค จึงเหมาะกับการอ่านแบบนี้) แล้วเดาว่าตัวถัดไปคืออะไร:

```
x = E[ตัวอักษร] + P[ตำแหน่ง]
ทุกชั้น:   A = softmax(Q·Kᵀ / √d_k)          ← มองย้อนกลับไปอ่านตัวก่อนหน้า
           x = x + A·V·W_o
           x = x + GELU(LayerNorm(x)·W₁)·W₂  ← คิดต่อ
p(ตัวถัดไป) = softmax(z / T)
```

ตอนฝึก: `L = −(1/N) Σ ln p(ตัวที่ถูก)` แล้วปรับน้ำหนักด้วย AdamW `θ ← θ − η · m̂/(√v̂+ε)`

| ขนาดสมอง | ชั้น | d | มองย้อน | น้ำหนัก |
|---|---|---|---|---|
| เล็ก | 4 | 128 | 128 ตัวอักษร | ~0.8 ล้าน |
| กลาง (เริ่มต้น) | 6 | 256 | 256 ตัวอักษร | ~4.9 ล้าน |
| ใหญ่ | 8 | 384 | 256 ตัวอักษร | ~14.4 ล้าน |

## 🎓 สมองโต: ให้แซนด์ฉลาดขึ้นทันที

กดปุ่ม **🧠 เลือกสมอง** มุมขวาบน แล้วดาวน์โหลดสมองโตหนึ่งตัว (ครั้งแรกครั้งเดียว ต้องต่ออินเทอร์เน็ต)
หลังจากนั้นแซนด์คิดบนเครื่องคุณแบบออฟไลน์ทั้งหมด

| สมอง | น้ำหนัก | ขนาดไฟล์ | เหมาะกับ |
|---|---|---|---|
| Qwen3 0.6B | 0.6 พันล้าน | ~1.5 GB | เครื่องช้า / อยากได้คำตอบเร็ว |
| **Qwen3 1.7B** | 1.7 พันล้าน | ~4.1 GB | **แนะนำสำหรับ RAM 8GB** · คิดก่อนตอบได้ |
| Typhoon 2.5 (Qwen3 4B) | 4 พันล้าน | ~8.1 GB | ภาษาไทยเก่งที่สุด · ต้อง RAM 16GB |

**สร้างเองตรงไหน:** น้ำหนัก (ความรู้) มาจากโมเดลเปิดที่ฝึกมาแล้ว แต่ตัวที่ “คิด” คือ `bigbrain.py` ที่เขียนเองทุกสูตร
(RMSNorm, RoPE, Grouped-Query Attention, SwiGLU, KV cache, การสุ่มแบบ top-k/top-p) อ่านไฟล์ safetensors เอง ไม่ใช้ Ollama หรือ transformers
ผลลัพธ์ตรงกับโค้ดต้นแบบของ Qwen3 ทุกตัวเลข (ต่างกันไม่เกิน 0.0000004)

**ในแท็บ 🧠 สมองสด** จะเห็นทุกโทเคนพร้อมสูตรจริง: attention ที่มี RoPE, สัญญาณผ่านทั้ง 28 ชั้น, softmax จาก 151,936 โทเคน, entropy
และถ้าเปิด “ให้คิดก่อนตอบ” จะเห็นแซนด์คิดในใจแบบสด (💭 ตัวเอียง) ก่อนตอบ

**สอนสมองโตได้:** สิ่งที่สอนในแท็บข้อมูลฝึกถูกส่งให้อ่านก่อนตอบทุกครั้ง และข้อความยาวที่ป้อนไว้ จะถูกค้นส่วนที่เกี่ยวข้องมาให้อ่านด้วย
(สมองโตไม่ได้ฝึกน้ำหนักใหม่บน Mac 8GB เพราะแรมไม่พอ ส่วนแซนด์ทารกยังฝึกได้ตามเดิม)

**ระดับความฉลาด (ตรงไปตรงมา):** Qwen3 1.7B ตอบความรู้ทั่วไป อธิบาย และคำนวณได้ดีระดับมัธยมปลายถึงต้นปริญญาตรีในหลายเรื่อง แต่ยังผิดได้ โดยเฉพาะข้อเท็จจริงเฉพาะทางและภาษาไทยซับซ้อน · ถ้าอัปเกรดเป็นเครื่อง 16GB ขึ้นไป ใช้ Typhoon 2.5 จะเก่งภาษาไทยขึ้นชัดเจน

## 🌐 เรียนรู้จากอินเทอร์เน็ต (ปิดไว้เป็นค่าเริ่มต้น)

เปิดได้ที่แท็บ 📚 ข้อมูลฝึก → “อนุญาตให้แซนด์ใช้อินเทอร์เน็ต”

- **อ่านจาก:** ทั้งเว็บ + Wikipedia / ทั้งเว็บเท่านั้น / Wikipedia เท่านั้น
- **เครื่องมือค้นหา:** DuckDuckGo (ฟรี ไม่ต้องสมัคร แต่ไม่มี API ทางการ ถ้าค้นถี่อาจถูกขอให้ช้าลง)
  หรือ Tavily (เสถียรกว่า · สมัครฟรีที่ tavily.com ได้ 1,000 ครั้ง/เดือน · ใส่ API key ในแอป เก็บไว้ในเครื่องคุณเท่านั้น)
- **🌱 แซนด์ทารกออกไปอ่านเอง** — ตั้งหัวข้อไว้ จะค้นจากเว็บ/Wikipedia แล้วเปิดอ่านทีละหน้า · ไม่ตั้ง จะสุ่มบทความ Wikipedia · เอาไปฝึกอัตโนมัติ (สูตร `w_web`)
- **🎓 สมองโตค้นก่อนตอบ** — คิดคำค้นเอง → ค้น → เปิดอ่าน 2 หน้า (ต่างเว็บกัน) → ตอบพร้อมที่มา → จำไว้ใช้ตอนออฟไลน์ · พิมพ์ `ค้น: …` เพื่อบังคับค้น

**มารยาทและความปลอดภัยของตัวอ่านเว็บ (`web.py`)**
- เคารพ `robots.txt` ของทุกเว็บ · เว้นระยะอย่างน้อย 2 วินาทีต่อเว็บ · Wikipedia ใช้ API ทางการ ไม่เกิน 1 ครั้งต่อวินาที
- อ่านเฉพาะหน้าเว็บข้อความ ตัดเมนู โฆษณา คุกกี้ และส่วนท้ายเว็บทิ้ง
- ไม่ยอมเปิดที่อยู่ในเครือข่ายภายใน (เช่น 192.168.x.x, localhost) แม้ผลค้นหรือการ redirect จะพาไป
- เปิดแล้วแซนด์ไม่ออฟไลน์ 100% · ข้อมูลในเว็บผิดได้ แซนด์จึงแนบลิงก์ที่มาเสมอ · เนื้อหาที่อ่านเก็บไว้ในเครื่องคุณเพื่อใช้ส่วนตัว

## ในแอปมีอะไร

- **🧠 สมองสด** — ตอนแซนด์ตอบ จะเห็นทุกตัวอักษรที่คิดแบบเรียลไทม์ พร้อมสูตรที่แทนค่าตัวเลขจริง
  ① attention: มองย้อนไปที่ตัวไหน (ไฮไลต์สีเขียว) ② สัญญาณผ่านแต่ละชั้น ③ softmax: ตัวเลือกทั้งหมดพร้อมความน่าจะเป็น ④ entropy: ลังเลแค่ไหน
  ปรับอุณหภูมิ T, top-k และความเร็วได้ คลิกตัวอักษรใดก็ได้เพื่อย้อนดู หรือกด 🔬 ใต้คำตอบเก่า
- **📈 การฝึก** — กราฟ loss สด สูตร loss / AdamW / ขนาดสมองพร้อมตัวเลขปัจจุบัน และ "แซนด์ลองพูด" ทุก 300 ก้าว ให้เห็นพัฒนาการตั้งแต่พูดมั่วจนพูดเป็นประโยค
- **📐 สูตร** — XP, เลเวล, ความเก่ง และสูตรที่ครูฝึกใช้จริง (อัตราการเรียนรู้ `lr`, น้ำหนักข้อมูล) แก้ได้ทั้งหมด สร้างสูตรใหม่ได้ ดูกราฟของสูตรได้
- **📚 ข้อมูลฝึก** — สอนคู่ถาม-ตอบ, ป้อนข้อความยาวหรือไฟล์ .txt ให้อ่าน, ดูว่าแซนด์เรียนจากอะไรบ้าง
- **💬 ในแชท** — 👍 ทำให้แซนด์อ่านคำตอบนั้นซ้ำตอนฝึก, ✏️ สอนคำตอบที่ถูกได้ทันที

## ข้อมูลฝึกเพิ่มเติม (`data/`)

ชุดข้อมูลที่เขียนขึ้นใหม่ทั้งหมด ป้อนได้ที่แท็บ 📚 ข้อมูลฝึก → **📄 เปิดไฟล์ .txt** (เลือกหลายไฟล์พร้อมกันได้)

| ไฟล์ | เนื้อหา |
|---|---|
| `1-บทสนทนา.txt` | บทสนทนาชีวิตประจำวัน ~130 คู่ (ทักทาย ความรู้สึก ให้กำลังใจ เรื่องของแซนด์เอง) |
| `2-ความรู้รอบตัว.txt` | ถาม-ตอบความรู้ ~120 ข้อ (ดาราศาสตร์ วิทยาศาสตร์ ร่างกาย ประเทศไทย ภูมิศาสตร์ คอมพิวเตอร์ สัตว์) |
| `3-เรื่องเล่า.txt` | นิทานและความเรียงสั้น 15 เรื่อง สำหรับฝึกภาษาไทยที่เป็นธรรมชาติ |
| `4-คณิตศาสตร์.txt` | 1,136 ข้อที่สร้างด้วยโปรแกรม (สูตรคูณ หาร บวกลบสองหลัก เปรียบเทียบ คู่/คี่ อ่านตัวเลขไทย) |

ไฟล์ถาม-ตอบใช้รูปแบบ `ผู้ใช้: … / แซนด์: …` เหมือนตอนคุยจริง แซนด์จึงเรียนวิธีตอบได้โดยตรง
อยากเพิ่มเอง เขียนไฟล์ .txt รูปแบบเดียวกันแล้วป้อนเข้าไปได้เลย

## ตรงไปตรงมาเรื่องความฉลาด

AI อย่าง Claude ฝึกด้วยข้อความหลายล้านล้านคำบนการ์ดจอหลายพันใบ แซนด์ฝึกบนเครื่องเดียวด้วยข้อมูลไม่กี่หมื่นถึงไม่กี่ล้านตัวอักษร
จึงจะไม่มีวันฉลาดเท่า แต่จะเรียนรู้สิ่งที่คุณสอนได้จริง และคุณเห็นทุกขั้นของการคิด

**ทำให้แซนด์เก่งขึ้น:** ป้อนข้อความภาษาไทยเยอะๆ (ยิ่งหลากหลายยิ่งดี ใช้เฉพาะข้อความที่คุณมีสิทธิ์ใช้) · สอนคู่ถาม-ตอบ · ฝึกนานๆ · เปลี่ยนเป็นสมองใหญ่เมื่อมีข้อมูลเยอะแล้ว
ถ้าเส้น loss ตอนฝึก (สีทอง) ต่ำกว่าเส้นข้อความใหม่ (สีเขียว) มากขึ้นเรื่อยๆ แปลว่าแซนด์กำลัง "ท่องจำ" มากกว่า "เข้าใจ" ควรป้อนข้อมูลใหม่เพิ่ม
